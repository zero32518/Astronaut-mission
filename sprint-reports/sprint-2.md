# Sprint 2 Report: Solution Approach and Architecture

## Objective
To develop the logical framework, threshold algorithms, and test modules for the astronaut health monitoring and alert system.

## Key Activities
* **Resource Monitoring Logic:** Designed threshold algorithms for oxygen and water levels that trigger immediate visual and audio alerts when values drop below safe margins.
* **Cognitive and Reflex Testing:** Outlined testing modules to measure astronaut reaction times, coordination, and mental health status.
* **NASA Data Evaluation:** Integrated NASA health statistics to automatically evaluate test performance against standardized health metrics, categorizing results as "Good", "Bad", or "Critical Risk".

## Next Steps
* Code the software prototype and integrate all monitoring and testing components into a functional user interface.
